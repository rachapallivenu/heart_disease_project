# Heart Disease Prediction App ❤️

This project is a machine learning web application built with Streamlit that predicts the risk of heart disease based on user input parameters.

## 🚀 Features

- Predicts heart disease risk using multiple ML models (Random Forest, SVM, KNN, Decision Tree, etc.)
- Interactive web interface for user input
- Visualizes model performance and risk factors
- Provides health recommendations and a high-risk management guide

## 🖥️ How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rachapallivenu/heart_disease_project.git
   cd heart_disease_project
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(If you don't have a `requirements.txt`, let me know and I can help you create one!)*

3. **Run the app:**
   ```bash
   streamlit run heart_disease_app.py
   ```

4. **Open your browser:**  
   Go to the URL shown in the terminal (usually [http://localhost:8501](http://localhost:8501)).

## 📁 Project Structure

- `heart_disease_app.py` — Main Streamlit app
- `heart_disease_dataset.csv` — Dataset used for training and predictions
- `Heart_Disease_Detection.py` — (Optional) Additional scripts
- `mini/` — Project documents and presentations

## 📝 Usage

- Adjust the health parameters in the sidebar.
- Click "Predict Heart Disease Risk" to get your risk assessment.
- Explore the tabs for model performance, risk analysis, and health guides.
